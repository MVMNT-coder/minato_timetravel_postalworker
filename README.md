# 未来救出局 — あなたは未来を救えるか!?

AIの最適化で停滞した2060年。そこに住む未来人・minatoからのリクエストに応えて、身の回りの物をカメラで撮って未来へ送ります。送った物しだいで、2060年の世界が「救われる」「あと一歩」「色を失う」のどれかになります。

## ページ

| ファイル | 内容 |
|---|---|
| `index.html` | **メイン：未来救出局**。タイトル → minatoの説明 → ミッション → minatoのリクエスト → カメラ → 時空転送 → 結果 |
| `gift.html` | 旧バージョン：未来便。品物が2060年でどう変わるかをminatoがツッコむ |

## 構成

- 画面：GitHub Pages
- 中継：Google Apps Script（`gas/Code.gs`）。Claude API のキーはここに隠します
- 記録：スプレッドシートに1回ずつ追記し、写真は Google ドライブに保存します
  - `mission_log`：未来救出局（index.html）。TOPの「救われた世界／救えなかった世界」の数はこのシートから集計
  - `log`：旧バージョン（gift.html）

```
ブラウザ（カメラ） ──写真──▶ GAS ──▶ Claude API
                    ◀─結果──   │
                               ├─▶ スプレッドシート
                               └─▶ ドライブ（minato_images）
```

## セットアップ

### 1. Claude API キーを用意する
1. [Claude Console](https://console.anthropic.com) で API キーを発行します。
2. 使いすぎを防ぐため、Console の「Limits」で月の利用上限を設定しておきます。

### 2. スプレッドシートと GAS を作る
1. Google スプレッドシートを新規作成します（名前は自由）。
2. メニューの「拡張機能 > Apps Script」を開きます。
3. `コード.gs` の中身を全部消し、このリポジトリの `gas/Code.gs` を貼り付けて保存します。
4. 左メニューの「プロジェクトの設定（歯車）」の一番下にある「スクリプト プロパティ」に、次を追加します。

| プロパティ | 値 | 必須 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 発行した API キー | ○ |
| `MODEL` | 使うモデル（既定 `claude-sonnet-5-5`） | |
| `RATE_PER_MIN` | 1分あたりの受付上限（既定 `30`） | |
| `SAVE_IMAGES` | `false` にすると写真を保存しない | |

5. エディタ上部の関数選択で `setupCheck` を選んで「実行」します。許可の画面が出るので、自分のアカウントで許可します。シートに `log` タブと動作確認の行ができれば成功です（確認の行は消してかまいません）。

### 3. ウェブアプリとして公開する
1. 右上の「デプロイ > 新しいデプロイ」を開き、種類に「ウェブアプリ」を選びます。
2. 次画面で次のように設定して、デプロイします。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. 表示された URL（`https://script.google.com/macros/s/…/exec`）をコピーします。ブラウザで開いて `{"ok":true,…,"ready":true}` と出ればOKです。

> `Code.gs` を書き換えたときは、「デプロイを管理」から既存のデプロイを編集し、バージョンを「新バージョン」にして更新します。URL は変わりません。

### 4. ページに URL を設定して公開する
1. `config.js` の `window.GAS_URL = "";` の `""` の中に、手順3でコピーした URL を貼って commit します。
2. GitHub のリポジトリで「Settings > Pages」を開き、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
3. 数分後に `https://mvmnt-coder.github.io/minato_timetravel_postalworker/` で開けます。

## 運用メモ
- **費用**：撮影1回につき Claude API を1回呼びます。費用はキーを発行したアカウントに請求されます。
- **連打対策**：GAS 側で1分あたりの受付数を制限しています（`RATE_PER_MIN`）。
- **写真の保存**：来場者の写真がドライブに残ります。画面にも「保存されます」と表示しています。不要なら `SAVE_IMAGES` を `false` にしてください。
- **GAS の上限**：無料の Google アカウントでは外部通信が1日2万回まで、同時実行は30件程度までです。展示の規模なら通常は足ります。
- **プロンプトの調整**：未来救出局のAIへの指示は `gas/Code.gs` の `PROMPT_MISSION`、停滞の設定とリクエストは `MISSION_STORIES` にあります。`MISSION_STORIES` は `index.html` の `STORIES` と同じ順番にそろえてください。書き換えたら新バージョンとしてデプロイし直します。
- **集計のリセット**：`mission_log` シートの2行目以降を消すと、TOPの世界の数が0に戻ります。
